# Configure Linux For Work

Concise, copy-pasteable guides for turning a fresh Ubuntu / GNOME install into a
comfortable, productive work machine — plus the small tools built along the way.

## Guides

| Guide | What it covers |
| --- | --- |
| [Firefox (snap): Save As fix](firefox-snap-save-as-fix.md) | Save dialogs silently failing and Desktop not reachable in the Firefox snap. |
| [Show hidden files (GNOME)](gnome-show-hidden-files.md) | Globally show hidden files and folders. |
| [Configure GitHub token globally](github-global-token-config.md) | Store a GitHub token so `git` never prompts again. |
| [Cloning private GitHub repos with a PAT](github-private-repo-pat.md) | Clone private repositories using a personal access token. |
| [GitHub PAT workflow](github-pat-workflow.md) | Clone, push and release with a PAT. |
| [npm: full install logs](npm-full-logs-config.md) | Always show full npm install logs. |
| [OpenCode: enable text copy](opencode-enable-text-copy.md) | Restore terminal select-and-copy in the OpenCode TUI. |
| [MD File Viewer](md-file-viewer.md) | Native GitHub-style Markdown viewer/editor — install and usage. |

## Apps

## How to use this repo

Every guide is a standalone Markdown file that follows the same shape: the
problem, the cause, the exact commands, and how to apply and verify the fix.
Open the file you need from the table above.
